# “秋风”GeoGebra 初中数学语料评估

评估日期：2026-08-04
公开来源：<https://www.geogebra.org/u/秋风>

## 结论

这是一个高价值的八、九年级动态数学语料簇，不只是静态题图。完整加载主页后得到 180 个顶层资源；递归展开 Book 后得到 183 个独立材料，其中 182 个为 Activity。182 个 `.ggb` 全部可以离线静态解析，未执行任何 GGBScript 或 JavaScript。

现有 FamTutor 原子命令已经能解释 6,388 / 6,647（96.1%）个 GeoGebra 构造命令。但当前最大的缺口不在基本几何，而在“布尔控件驱动的条件显隐”：180 / 182 个 Activity 含条件显隐，共 2,601 条规则。这应成为下一项底层能力。

原始 `.ggb`、缩略图和页面快照保存在仓库外研究目录；仓库只保存采集器、Inspector、统计结论和原创复现方案。

## 命令覆盖与能力缺口

### 已能解释

现有底层已覆盖点、线、线段、射线、相交、垂线、圆、多边形、角、旋转、镜像、平移、向量、Sequence 等主体命令。命令出现次数最高的是：

- `Segment` 2,193
- `Point` 704
- `Intersect` 701
- `Angle` 650
- `Polygon` 644
- `OrthogonalLine` 315
- `Rotate` 225
- `Ray` 209
- `Circle` 156
- `Line` 143

### 明确底层缺口

| 所需能力 | 命令次数 | 设计方向 |
|---|---:|---|
| 通用条件显隐 | 2,601 条规则 | Boolean Entity + `boolean.set/toggle` + Entity `visibleWhen`；属于展示状态，不改变几何定义 |
| `transform.stretch` | 74 | 先按 GeoGebra 两种重载做类型解析，再决定一个仿射变换原子或两个明确原子 |
| `point.in_region` | 17 | 返回受区域约束的自由点；拖拽投影策略必须与区域边界语义分开 |
| `locus.trace` | 8 | 确定性采样轨迹，不把截图式 trace 当作几何实体 |
| `mirror` 重载解析 | 3 | Inspector 增强类型证据，避免新增重复变换 API |
| 通用路径相交 | 1 | 统一路径类型分派，不增加案例专用命令 |

### 可通过别名或 Macro 吸收

以下 147 次未知命令大多不需要新的重量级内核：`CurveCartesian`、`Semicircle`、`Centroid`、`If`、`PolyLine`、`Vertex`、`Text`、`Join`、`CircleSector`、`LaTeX`、`TableText`。应先逐一核对参数重载，再映射到 `curve.parametric`、arc/sector、三角形重心 Macro、布尔表达式、折线、顶点选择和文本注释能力。

`Extremum`（7）和 `LocusEquation`（2）属于函数/符号计算边界，单独排期，不为几何第一轮扩张内核。

## 第一轮原创复现样本

先复现 12 个“定理模型”，不直接复制其外观或脚本：

1. `u4wxhzvc`：三角形的定义
2. `xj2v8jyb`：三角形的内角和
3. `ayf6zvr6`：边边边全等判定
4. `ttsejkbj`：为什么没有边边角判定
5. `cuvejxbu`：一线三等角（全等）
6. `cn8uazqn`：线段垂直平分线的性质
7. `eb5zzh3j`：轴对称最短路径
8. `sw7nbppf`：勾股定理的证明
9. `kguph7a6`：n 边形的对角线
10. `eugqchbb`：平移、翻折、旋转的性质
11. `xbq2dzub`：一次函数的图象和性质
12. `y3mgqmzm`：二次函数 `y=ax²` 的图象和性质

每个样本生成自己的 `semantic brief`：题意、对象、约束、控件、状态、关键帧、需要的原子接口、可复用 Macro、视觉策略和断言。只有双渲染器与交互不变量同时通过，才进入基础素材库。

## 推进顺序

1. **P0：Boolean Control + Conditional Visibility**。它直接覆盖 180 个 Activity 的教学分步表达。
2. **P1：语义证据抽取**。从题名、缩略图和 `.ggb` 中提取可追溯但不执行的题意/状态证据，生成 Semantic Brief。
3. **P2：轻量映射与 Macro**。吸收 `CurveCartesian`、`Semicircle`、`Centroid`、`If`、`PolyLine`、`Vertex` 等。
4. **P3：Stretch / PointIn / Locus**。按重用性依次补充经过类型约束的底层原子能力。
5. **P4：12 个代表 Case**。逐个实现并在 Web Gallery 做初始态、操作态、结论态验收。
6. **P5：批量生成闭环**。模型输入“图片＋文本＋结构 Manifest”，输出 Semantic Brief → Capability Plan → FamTutor Document → 自动验证报告。

这条路线的目标不是“导入 182 个 GeoGebra 文件”，而是用它们把模型可调用的几何语言、交互语言和验证语言补齐，最后能从新题的图片与文本独立生成可维护的原创素材。
