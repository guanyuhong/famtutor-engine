# 第二章“特殊三角形”几何视觉与实现规划

状态：`source-reviewed / incremental-implementation`

教材：浙江教育出版社《义务教育教科书·数学八年级上册》

范围：第二章“特殊三角形”，正文印刷页 48–82 / PDF 页 51–85；目录所列 2.1–2.8 八节。

## 1. 实现原则

第二章继续采用第一章已经确认的四类独立验收证据：

1. `sourceFidelity`：页码、图号、点名、条件、结论和教学顺序可追溯；
2. `mathCorrectness`：构造关系、测量、面积和证明断言正确；
3. `visualQuality`：轴线、等长刻痕、角弧、直角和辅助线遵守统一视觉语言；
4. `runtimeStatus`：静态渲染、MountedRenderer、阶段切换和 Render Bundle 可确定性重放。

精确数学图只通过 Math Runtime 的公开接口生成。照片、建筑和历史插图只作为教材背景来源，不作为几何结论的证据。

## 3. 底层能力审计

### 3.1 已有能力直接覆盖

- 轴对称：`transform.reflect` + `transform.apply`，支持点、线性对象、圆、多边形、圆弧和扇形；
- 对称点作图：`point.projection`、`line.perpendicular_through`、`transform.reflect_point_line`；
- 全等与对应关系：`marker.segment_tick`、`angle.three_points` 和数值断言；
- 直角三角形：`marker.right_angle`、`point.midpoint`、`point.projection`；
- 勾股面积模型：`polygon.vertices`、`measurement.area`、`circle.center_radius`、圆弧/扇形；
- 动态探索：`point.on_path`、`point.from_expressions`、`scalar.slider` 和受限表达式；
- 证明阶段：`activity.stages` 的 `reveal` / `focus` / `narration`。

### 3.2 当前不新增接口

正方形、半圆和外作图形都是由已有点、向量、旋转、圆弧和多边形组合得到的教学构图，不是新的数学原子。第一批案例不得增加 `square.*`、`isosceles.*` 或 `pythagorean.*` 等题型化命令。

只有在组合过程中确认同一底层关系反复出现、现有接口无法保持跨渲染器一致时，才重新评估新 L0 原语。

## 5. 视觉与阶段约束

- 对称轴使用辅助线层级和虚线，不与主体轮廓同权；对应点使用教材撇号命名。
- 对称关系必须由反射变换产生，禁止只复制一组“看起来对称”的坐标。
- 等腰/等边关系必须显示标准等长刻痕；颜色只能用于分组强化。
- 勾股定理的面积图中，`S₁`、`S₂`、`S₃` 放在对应图形内部，推导放在 `narration`。
- 同一顶点的角弧继续遵守最多两个同时可见的限制；复杂证明拆阶段。
- 尺规或辅助构造轨迹使用低饱和虚线，结论阶段降低轨迹权重。
- 教材中的现实照片只转译成抽象几何模型，并在来源信息中说明映射关系。

## 6. 实现顺序

1. 2.1 轴对称：验证反射变换、对应点和最短路径；
2. 2.2–2.4 等腰三角形：复用等长刻痕、角弧和三线合一；
3. 2.5 逆命题：复用第一章命题阶段模型；
4. 2.6 直角三角形：复用直角标记、中点和等长关系；
5. 2.7 勾股定理：重点验证面积图与跨后端一致性；
6. 2.8 HL：以直角三角形全等和角平分线逆定理收束全章。
