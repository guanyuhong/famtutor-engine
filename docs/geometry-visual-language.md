# FamTutor 二维几何视觉语言

本规范用于教材几何图、探索活动和证明过程的静态与交互渲染。目标不是逐像素复制 GeoGebra，而是复用其适合课堂的视觉原则：几何关系优先、层级稳定、标记标准、文本不遮挡、交互前后不跳动。

## 1. 信息分层

几何画布只显示与当前阶段直接相关的内容：

1. **对象层**：点、线、线段、射线、圆、三角形和其他几何对象；
2. **关系层**：角弧、直角、等长、平行、垂直等标准标记；
3. **数值层**：`35°`、`2.5`、点名等短标签；
4. **叙事层**：题干、推导式、结论和操作说明，放在阶段 `narration`，位于画布外。

禁止用画布内长文本解释证明过程。需要强调某个关系时，优先通过 `stage.reveal`、`stage.focus` 和分阶段呈现降低信息密度。

## 2. 默认视觉参数

| 对象 | 建议参数 | 说明 |
|---|---:|---|
| 画布底色 | `#FFFEE8` 或白色 | 淡暖底适合教材案例，必须保证黑线对比度 |
| 主轮廓 | `2.0–2.4 px` | 深灰或黑色，三角形内部可使用白色低透明填充 |
| 辅助线 | `1.8–2.2 px` | 使用单一语义色；高度、角平分线等不要依赖颜色作为唯一线索 |
| 角弧/直角标记 | `1.4–1.8 px` | 黑色轮廓、白色或近白色填充 |
| 点 | 半径感知尺寸 `5–6 px` | 红色填充 `#F0202B`、黑色描边，保持与线端点清晰分离 |
| 点名 | `15–16 px` | 系统无衬线字体、常规字重；必要时使用浅色描边增强可读性 |
| 角值/短数值 | `15–16 px` | 比点名略小或等大，避免抢占几何关系的视觉主层级 |
| 临时聚焦 | 不超过 `3 px` | 仅用于阶段 focus，不改变数学对象的常态样式 |

颜色只是辅助编码。高度、角平分线、结果角必须同时由构造、标记或阶段叙事表达。

## 3. 角弧与角文本

`angle.three_points` 由两个相互独立的参数控制：

- `radius`：角弧半径，单位为文档坐标；默认 `0.6`；
- `labelRadius`：角文本中心沿角平分线到顶点的距离，单位为文档坐标。必须大于 `radius`；未提供时由渲染器根据角度、字体和文本宽度自动计算。

数学内核把三点角定义为不超过 180° 的小角；JSXGraph 必须显式使用官方 `selection: "minor"`，保证与 Direct SVG、测量和断言语义一致。反角若未来成为真实教材需求，应新增明确语义，而不能通过交换点序暗中改变。

渲染器应绘制近白色扇区和深色弧线，再沿角平分线放置标签。标签位置不得简单固定在弧线中点；自动布局需要考虑：

- 小角度时横向文本宽度；
- 钝角时标签与三角形边的间距；
- 顶点靠近视图边缘时的可见区域；
- Direct SVG 与 JSXGraph 使用相同的角度归一化与标签定位算法。

案例作者只有在自动布局无法满足教学意图时才显式设置 `labelRadius`。若同一顶点存在多个嵌套角，按内外顺序递增 `radius` 与 `labelRadius`，并在一个阶段最多显示两个角值。第三个关系应进入下一阶段，或只在阶段叙事中说明。

## 4. 点与标签

点标签默认使用 `EntityStyle.labelPlacement: "auto"`。渲染器在八个语义方位中进行确定性评分，标签与点之间至少保留点半径外约 7px 的呼吸空间，并避开标准标记、角扇区、角文本、相邻线段、其他点标签和画布边界。位于多边形顶点的点名优先放在多边形外侧；候选标签中心落入多边形内部时视为冲突。Direct SVG 与 JSXGraph 共用布局算法。

JSXGraph 后端必须使用点对象的原生 `Label` 与像素 `offset`，不能把点名退化为独立世界坐标文本。共享布局算法输出屏幕像素偏移，JSXGraph 原生标签负责跟随拖动、缩放和画布更新；这样既沿用官方标签锚点机制，也保持与 Direct SVG 的确定性位置一致。官方 `autoPosition` 可用于无领域结构的自由图，但教材多边形需保留“外侧优先”的几何语义。

作者可指定 `top`、`top-right`、`right`、`bottom-right`、`bottom`、`bottom-left`、`left` 或 `top-left`。`EntityStyle.labelOffset: [dx, dy]` 仅用于从选中锚点继续微调，单位为 CSS 像素；正 x 向右，正 y 向下。标签布局属于视觉样式，不进入几何构造。

推荐偏移：

- 上方顶点：`[8, -12]`；
- 左下顶点：`[-22, 18]`；
- 右下顶点：`[8, 18]`；
- 边上辅助点：优先放在线段外侧，并避开直角或等长标记。

点名应位于点附近，但不能覆盖边、角弧或数值。需要移动标签时只调整 `labelOffset`，不要改变点坐标来迁就文字。

## 5. 线条、填充与层级

推荐绘制顺序：画布背景 → 网格/坐标轴 → 面填充 → 主轮廓与辅助线 → 关系标记 → 点 → 标签。这样既能维持 GeoGebra 式的清晰边界，也避免点被线条吞没。

三角形或多边形可使用白色填充，透明度约 `0.9–1.0`。同一阶段不要同时使用多种高饱和辅助色。构造线必须能通过点名、标准标记或阶段叙事识别，不能只靠颜色。

### 5.1 路径标签

线段、直线和射线的名称或短数值使用 JSXGraph 1.12.2 官方路径标签语义：

- `lineLabelPosition`：沿第一点到第二点的比例位置，默认 `0.5`，即几何中点；
- `lineLabelSide`：从第一点朝第二点观察时的 `left` 或 `right`，默认 `left`；
- `lineLabelDistance`：标签相对路径的法向距离，默认 `1.6`，单位为半个标签文本框高度的倍数；
- `labelOffset`：官方定位完成后的像素微调，默认 `[0, 0]`。

JSXGraph 映射为 `position: "0.5fr left"`、`distance: 1.6`、`anchorX/Y: "middle"`。文本保持水平，不默认沿斜边旋转；这与教材及 GeoGebra 的短边长标注更一致。标签不得直接覆盖路径笔画。

多边形名称不属于某一条边。JSXGraph 使用官方 `getTextAnchor()`，Direct SVG 使用多边形面积质心，均以中央锚点绘制。边长测量若需要动态数值，优先使用 JSXGraph Smartlabel/运行时 measurement，而不是把计算结果硬编码到名称中。

路径标签配置只适用于 `line2`、`segment2` 和 `ray2`。滑杆数值使用 JSXGraph `Slider.label` 的默认点锚语义，不能继承路径的 `position` / `distance`；显示小数位由 `scalar.slider.params.step` 推导，避免整数步长显示为 `3.0000` 这类冗余文本。

## 6. 底层接口职责

| 接口 | 原子职责 | 不负责 |
|---|---|---|
| `graphics2d.background` | 定义画布底色 | 题目级卡片背景或主题系统 |
| `EntityStyle.labelPlacement` | 自动避让或指定点标签的语义方位 | 改变几何坐标、任意自由坐标布局 |
| `EntityStyle.labelOffset` | 从已选锚点提供像素级微调 | 替代自动避让、改变几何坐标 |
| `EntityStyle.lineLabelPosition` | 定义线性路径标签沿路径的比例位置 | 改变线段几何或自由文本坐标 |
| `EntityStyle.lineLabelSide` | 定义路径标签位于有向路径哪一侧 | 自动判断教材语义 |
| `EntityStyle.lineLabelDistance` | 定义标签离开路径的法向距离 | 任意二维位移 |
| `angle.three_points.params.radius` | 定义角弧的几何半径 | 标签位置 |
| `angle.three_points.params.labelRadius` | 定义角值沿平分线的位置 | 角的数学大小 |
| `marker.right_angle(angle)` | 从现有 90° 角生成标准直角标记 | 重新定义三个点或重复判定角度 |
| `marker.segment_tick(segment)` | 在已有线段上生成一条垂直等长刻痕；`size` 使用文档单位，`position` 是沿线段比例 | 判断两段是否等长、一次生成整组对应边或绑定案例语义 |
| `marker.parallel_chevron(anchor, lineLike)` | 在锚点处按线性对象方向生成一个标准平行箭形的两条短臂；`size` 使用文档单位 | 判断两线是否平行、替作者选择位置、一次生成双箭形 |
| `stage.reveal/focus` | 控制教学阶段的信息密度 | 改变数学真值或永久样式 |

这些接口均应保持通用、原子和后端一致。若未来需要自动标签避碰，应作为独立布局能力设计，不把案例特例塞进 `angle.three_points`。

## 7. 作者流程

1. 先按教材建立完整、正确的数学构造与断言；
2. 用默认样式渲染，检查几何关系是否无需解释即可辨认；
3. 设置画布范围和底色，避免对象贴边；
4. 先由 `labelPlacement: auto` 解决一般点名冲突；教学图需要固定方位时指定语义位置，最后才使用 `labelOffset` 微调；通过 `radius`/`labelRadius` 解决角标记；
5. 对应边的等长关系使用 `marker.segment_tick`；一、二、三刻痕由相同原语在不同 `position` 组合，不用文字或颜色代替；
6. 将嵌套角和推导拆成阶段，删除画布内冗长文字；
7. 同时截图 Direct SVG 与 JSXGraph，逐阶段比较；
8. 验证窄角、钝角、缩放、阶段切换和确定性指纹。

## 8. 验收清单

- 主轮廓、辅助线和角弧层级清楚，没有不必要的粗线；
- 点、点名、角弧、角值和直角标记互不遮挡；
- 单个顶点没有超过两个同时可见的角值；
- 画布内不存在可移到阶段叙事中的长句或长公式；
- 缩放或切换阶段时，标签没有明显跳动或跑出画布；
- Direct SVG 与 JSXGraph 对背景、标签偏移、角半径和阶段可见性具有相同语义；
- 颜色关闭或灰度显示时，构造关系仍可识别；
- 数学断言、来源忠实度和交互行为没有因视觉调整改变。
