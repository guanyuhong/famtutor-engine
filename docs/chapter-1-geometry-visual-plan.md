## 1. 目标

本轮不以“生成更多可运行案例”为第一目标，而以以下四项同时成立为验收条件：

1. `sourceFidelity`：图、条件、结论和教学顺序可追溯到教材中的具体页、图号或题号；
2. `mathCorrectness`：构造约束、测量、推理和最终答案正确；
3. `visualQuality`：标签不遮挡、层级明确、辅助线与主体线可区分；
4. `runtimeStatus`：案例可确定性重放、静态渲染、浏览器挂载和交互。

旧的单一 `accepted` 不能代替这四项。

## 4. 正式视觉规范

### 4.1 色彩

| 角色 | 建议颜色 | 用途 |
|---|---|---|
| 主体几何 | `#15365F` 深海军蓝 | 三角形主体边、主要文字 |
| 定义/关系 | `#0E8378` 青绿色 | 中线、角平分线、等长关系 |
| 当前推理 | `#EF6C22` 橙色 | 当前角、当前结论、交互反馈 |
| 辅助构造 | `#2E6DB2` 蓝色 | 辅助线、证明线、尺规轨迹 |
| 正确状态 | `#DCEFE7` 淡薄荷绿 | 正确反馈背景 |
| 画布 | `#FAF8F2` 暖白 | 降低纯白画布的刺眼感 |

颜色不能单独承担数学语义；等长、等角、垂直和平行必须同时使用标准几何标记。

### 4.2 线型

- 主体边：2.5 px，实线；
- 当前高亮：3.5 px，实线；
- 辅助线：2 px，虚线或低饱和蓝；
- 尺规轨迹：1.5 px，半透明圆弧；
- 延长线：2 px，虚线；
- 点：半径 5–6 px；
- 直角标记、等长刻痕和角弧使用独立几何对象，不嵌入文字。

### 4.3 标签

- 点名与点保持 8–12 px 间距；
- 标签不得压在线、角弧或填充区域上；
- 角度数值靠近角弧，不靠近顶点中心；
- 同一画面最多突出一个“当前结论”；
- 教材原题点名不得任意替换。

### 4.4 教学阶段

每个推理案例使用统一阶段：

1. `source`：显示教材锚点和原题摘要；
2. `given`：只显示已知条件；
3. `construct`：添加辅助线或构造；
4. `derive`：逐步显示中间结论；
5. `conclude`：突出最终结论；
6. `explore`：允许拖动或改变参数，检查结论边界。

## 5. 首个精确案例：CH1-09

### 5.1 来源

- 印刷页：8；
- PDF 页：11；
- 例题：例 2；
- 图号：图 1-7。

### 5.2 原题语义

在 `△ABC` 中：

- `AD` 是 `△ABC` 的高；
- `AE` 是 `∠BAC` 的角平分线；
- `∠BAC=80°`；
- `∠C=40°`；
- 求 `∠DAE`。

结论：`∠DAE=10°`。

### 5.3 建议精确坐标

使用固定、可验证的坐标构造教材初始图：

- `B=(0,0)`；
- `C=(9.192,0)`；
- `A=(3,5.196)`；
- `D=(3,0)`，为 A 到 BC 的垂足；
- `E≈(3.916,0)`，为 A 的内角平分线与 BC 的交点。

这些坐标满足：

- `∠ABC=60°`；
- `∠BAC=80°`；
- `∠ACB=40°`；
- `AD⊥BC`；
- `∠BAE=∠EAC=40°`；
- `∠DAC=50°`；
- `∠DAE=10°`。

正式文档保留更高精度，界面只显示教材需要的整数角度。

### 5.4 图层

1. 主体：`AB`、`AC`、`BC`；
2. 角平分线：线段 `AE`，青绿色；
3. 高：线段 `AD`，蓝色；
4. 标记：D 点直角标记；
5. 已知角：`∠BAC=80°`、`∠ACB=40°`；
6. 推导角：`∠EAC=40°`、`∠DAC=50°`；
7. 结论角：`∠DAE=10°`，橙色高亮。

### 5.5 阶段

| Stage | 画面 | 教学信息 |
|---|---|---|
| source | 教材图 1-7 对应关系 | 来源、题目条件和所求角 |
| triangle | 只显示 `△ABC` | `∠A=80°`、`∠C=40°` |
| bisector | 添加 `AE` | `∠EAC=40°` |
| altitude | 添加 `AD` 和直角标记 | `∠ADC=90°` |
| derive | 高亮 `△ADC` | `∠DAC=180°-90°-40°=50°` |
| conclude | 高亮 `∠DAE` | `∠DAE=50°-40°=10°` |

### 5.6 数学断言

至少验证：

- `angle(B,A,C)=80°`；
- `angle(A,C,B)=40°`；
- `AD ⟂ BC`；
- `B,D,E,C` 共线且顺序正确；
- `angle(B,A,E)=angle(E,A,C)`；
- `angle(D,A,C)=50°`；
- `angle(D,A,E)=10°`。

### 5.7 验收

- 点名、线名、条件和答案与图 1-7 一致；
- 不引入教材没有的“B 点直角”或“45°”；
- 图形比例接近教材，但以数学约束正确为优先；
- 六个教学阶段可以独立截图；
- Direct SVG 与 JSXGraph 均无标签遮挡；
- 同一 ChangeSet 重放两次 fingerprint 相同；
- 浏览器挂载后阶段切换不改变文档 revision；
- `sourceFidelity=A`、`mathCorrectness=passed`、`visualQuality=reviewed`、`runtimeStatus=accepted` 分开记录。
